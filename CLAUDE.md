# Contexto del Proyecto: TamZuri

## Visión General
TamZuri es una aplicación orientada a la seguridad personal al volver sola a casa.
Consta de:
1. App Móvil (Android): Registra el trayecto, envía el rastreo GPS en tiempo real y gestiona incidencias con PIN.
2. Backend (API REST): Desarrollado en Kotlin con Spring Boot.
3. Visor Web (Familiares): Cliente web en HTML/CSS/JS para visualizar la ruta sin necesidad de instalar la app.

## Directivas para la Asistencia de la IA
1. Análisis Previo de Decisiones: Antes de proponer o escribir código, analizar alternativas con sus ventajas e inconvenientes.
2. Código Progresivo y Explicado: Explicaciones modulares y adaptadas al nivel de DAM.
3. Arquitectura: Seguir buenas prácticas (MVVM en Android, Controller-Service-Repository en Spring Boot).

## Stack Tecnológico
- Móvil: Android Nativo en Kotlin con Jetpack Compose.
- Backend: Kotlin + Spring Boot.
- Frontend Web: HTML5, CSS3, JavaScript.
- Base de Datos: MySQL.
